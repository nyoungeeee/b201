# Random Nickname API Design

## Goal

신규 사용자가 가입 즉시 사용할 수 있는 기본 닉네임을 자동 부여하고, 비인증 클라이언트가 같은 규칙의 랜덤 닉네임 후보를 받을 수 있는 API를 제공한다.

## API

- Method: `GET`
- Path: `/api/v1/me/nickname/random/`
- Auth: 비인증 허용
- Response: `{"nickname": "고장난기타7"}`

## Generation Policy

- 닉네임은 `접두어 + 명사 + 숫자` 형식이다.
- 접두어와 명사는 고정 한글 단어 풀에서 랜덤 선택한다.
- 숫자는 `0`부터 `9`까지의 1자리 숫자다.
- 전체 닉네임은 숫자 포함 8자 이내다.
- 이미 사용 중인 닉네임은 피해서 생성한다.
- 제한된 재시도 안에 생성하지 못하면 서비스 오류를 발생시킨다.

## Integration

- 생성 책임은 `accounts` 앱 서비스에 둔다.
- 랜덤 닉네임 API와 신규 카카오 가입 로직은 같은 생성 서비스를 사용한다.
- 사용자가 이후 닉네임을 직접 변경하면 랜덤 닉네임과 별도 연결 상태를 저장하지 않는다.

## Tests

- 비인증 요청으로 랜덤 닉네임 API를 호출할 수 있다.
- 응답 닉네임은 정책 형식과 길이를 만족한다.
- 중복 닉네임이 선택되면 다른 닉네임을 재시도한다.
- 신규 카카오 가입 시 `nickname`이 자동 생성되어 저장되고 응답된다.
